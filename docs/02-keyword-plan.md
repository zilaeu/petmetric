# PetMetric 关键词规划与页面布局

**版本：** 2026-09-03  
**目标语言：** US English  
**原则：** 关键词服务于决策，不为了密度牺牲可信度和可读性。

## 1. 关键词战略

PetMetric 不与 Cats.com 争夺所有宠物百科词，也不做单纯的品牌评测站。关键词策略集中在四个有明确决策动作的垂直：

1. **Research**：用户想了解产品和类别
2. **Compare**：用户已经有两个候选
3. **Choose**：用户准备购买，需要场景化建议
4. **Fix**：用户已经购买，遇到具体问题

关键词优先级使用以下评分，而不是只看搜索量：

```text
Priority = 商业价值 × 用户意图 × PetMetric 专业匹配度 × 内容可胜任度 × 时效性
```

第三方工具的搜索量和难度应在正式写作前重新核验；本文件先定义内容方向、页面映射和防止主题冲突的规则。

## 4. 页面关键词布局

### Hub 页

关键词放置：

- SEO title：核心词 + 明确价值，例如 `Automatic Litter Boxes: Reviews, Comparisons & Costs`
- H1：核心词 + 用户结果
- 首段：自然包含核心词、适用场景和评估维度
- H2：`How We Compare`、`Top Products`、`Common Problems`、`Related Guides`
- Meta description：不堆品牌，说明页面能帮助用户做什么决定
- FAQ：回答价格、订阅、安全、清洁、兼容性等高频问题

### 评测页

建议模板：

```text
Title: [Product] Review: Cost, Reliability, Features & Alternatives
H1: [Product] review: who it is actually for
H2: Quick verdict
H2: Specs, price and subscription
H2: What works well
H2: Limitations and ownership costs
H2: Alternatives and comparisons
H2: Sources and last checked date
```

### 对比页

```text
Title: [Product A] vs [Product B]: Which Should You Buy?
H1: [Product A] vs [Product B]
H2: The short answer
H2: Feature and cost comparison
H2: Which is better for each use case?
H2: What we would choose—and why
H2: Related reviews and guides
```

### 故障页

```text
Title: [Product] Not [Working]: Causes and Fixes
H1: [Product] not [working]: step-by-step fixes
H2: Start with the safe checks
H2: Most common causes
H2: Fixes in order
H2: When to contact support
H2: Related problems
```

## 5. 内链关键词分配

| 页面 | 必须链接到 | 推荐锚文本 |
|---|---|---|
| 品类 Hub | 评测、对比、Best Picks、故障 | `automatic litter box reviews`、`compare litter boxes` |
| 评测 | 品类、至少 1 个对比、替代品 | `see how it compares`、`alternatives to ...` |
| 对比 | 两个单品评测、品类 Hub、购买指南 | `read our ... review` |
| Best Picks | 评测、对比、成本说明 | `best for multi-cat homes` |
| 故障 | 单品评测、官方支持、同类替代品 | `full ... review`、`contact support` |

## 6. 防止关键词蚕食

- `best automatic litter box` 只由一篇总指南作为主页面；品类 Hub 使用更宽的 `automatic litter boxes`。
- `Litter-Robot 5 review` 只由单品评测承接；对比页使用 `Litter-Robot 5 vs ...`。
- 品牌页不抢单品评测词，品牌页目标是品牌全景和产品集合。
- 故障页标题必须包含症状词，避免与产品评测共用 `review` 主词。
- 每新增一篇文章，先在关键词表登记主词、搜索意图、目标 URL 和 3 个内链目标。

## 8. SEO 验收

- 每页只有一个明确主关键词和一个主要搜索意图
- Title、H1、URL、首段和一个 H2 语义一致
- 不用关键词堆砌或重复的城市/品牌模板页
- 产品价格、订阅和规格显示来源及检查日期
- 文章包含作者、更新日期、编辑标准和联盟披露
- 使用 Article、Product、Review、ItemList、FAQPage、BreadcrumbList 中适用的结构化数据
- 图片使用真实产品图和描述性 alt，不把关键词写进无意义 alt
